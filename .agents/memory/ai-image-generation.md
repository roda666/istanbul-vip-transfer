---
name: AI image generation policy
description: Durable safety and publishing rules for AI-generated blog and service imagery.
---

AI-generated images run only on the server with an image-specific model setting that defaults to GPT Image 2. The app must persist generated assets before presenting them, expose only stable first-party storage paths, and require descriptive alt text before an editor can attach an image to public content.

**Why:** Provider image URLs expire and signed storage URLs grant temporary write access. Treating either as public content creates broken pages or exposes sensitive URLs. Required alt text is necessary for accessible, SEO-ready content.

**How to apply:** Keep provider calls, generated bytes, provider responses, API credentials, and signed URLs server-side. Store a verified web-optimized asset in a content-scoped location, validate that attachment ownership matches the selected blog or service, and invalidate affected public pages only after a successful content update. Preserve structured service content instead of appending raw Markdown to it.
