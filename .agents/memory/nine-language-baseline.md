---
name: Nine-language product baseline
description: The public site must be planned and verified across Turkish plus eight supported visitor languages.
---

Treat Turkish as the source language and always include EN, DE, RU, AR, FR, ES, IT, and NL in public-facing feature, content, routing, CMS, and quality decisions.

**Why:** The site is a nine-language product, not a Turkish site with optional translations. New work must not silently exclude the later-added locales or show Turkish source text on a non-Turkish page.

**How to apply:** For every public page or visitor flow, ensure a locale-aware implementation, localized missing-content state where content is incomplete, and RTL-specific treatment for Arabic. Include the complete language set when seeding content, designing CMS workflows, and defining regression coverage unless a feature is deliberately language-neutral.
