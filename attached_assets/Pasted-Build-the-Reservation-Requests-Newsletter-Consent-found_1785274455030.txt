PHASE 2 — Save quote and reservation requests

Recommended fields:
   - id
   - referenceNumber
   - intent: QUOTE or RESERVATION
   - serviceType
   - name
   - phone
   - normalizedEmail, nullable
   - locale/language
   - requestData JSONB containing only service-specific form data
   - status: NEW, CONTACTED, QUOTED, CONFIRMED, COMPLETED, CANCELLED, SPAM
   - createdAt
   - updatedAt
   - archivedAt, nullable

9. Create a secure public server-side submission endpoint:
   - validate with the project’s existing validation approach
   - normalize email addresses
   - sanitize and limit input lengths
   - add a hidden honeypot and reasonable rate limiting
   - do not log personal customer data
   - do not expose request records publicly
   - generate a human-readable unique reference number
   - save the request before continuing to WhatsApp

   - show the reference number
   - continue to the existing prefilled WhatsApp conversation

11. If database saving fails:
   - show a clear retry message

   - provide a direct WhatsApp fallback so the customer is not lost
