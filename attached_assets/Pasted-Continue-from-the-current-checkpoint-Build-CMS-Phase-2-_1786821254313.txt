4. Multilingual service workflow

Turkish is the source language.

Add locale tabs:

- Turkish — tr
- English — en
- German — de
- Russian — ru
- Arabic — ar

When Turkish content is changed and “Taslak Kaydet ve Çevir” is clicked:

- save the Turkish draft
- create or update translation jobs for selected active languages
- translate every translatable service field
- preserve formatting, brand names, phone numbers, IST, SAW, Mercedes Vito, Mercedes Sprinter and URLs
- keep Arabic RTL
- do not translate image paths, ordering, IDs, status or technical route mappings
- never report a translation as successful when Turkish text was merely copied
- if the AI provider fails or is not configured, mark the translation FAILED with a readable admin error
- never publish untranslated Turkish text on another locale

Required workflow:

Turkish draft
→ AI translation
→ locale review
→ admin approval
→ publish

No AI-generated translation may be published without admin approval.

Provide:

- “Taslak Kaydet ve Çevir”
- “Tüm Çevirileri İncele”
- per-language approve/reject controls
- “Onaylanan Dilleri Toplu Yayınla”
- clear statuses: Başlamadı, Çevriliyor, İncelemede, Onaylandı, Yayında, Hatalı
