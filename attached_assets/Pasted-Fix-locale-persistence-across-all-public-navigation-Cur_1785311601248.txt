Fix locale persistence across all public navigation.

Current bug:
After selecting English, German, Russian or Arabic, navigating to another page returns the website to Turkish.

   - Turkish: existing unprefixed URLs
   - English: /en/...
   - German: /de/...
   - Russian: /ru/...
   - Arabic: /ar/...

   Required behavior:
   - localePath("/", "en") => "/en"
   - localePath("/hizmetler", "en") => "/en/hizmetler"
   - localePath("/blog", "de") => "/de/blog"
   - Turkish links remain unprefixed
   - never create duplicate prefixes such as /en/en/...
